# AI-Generated Documentation

This folder contains all documentation created by Copilot AI and other AI assistants.

## Guidelines for Future Documentation

When requesting documentation from Copilot AI, use these instructions:

1. **Always specify the output path**: "Save this to `docs/ai/[filename].md`"
2. **Include the purpose**: Start your request with a clear description
3. **Follow naming conventions**: Use UPPER_CASE_WITH_UNDERSCORES.md for fix/implementation docs
4. **Add timestamps**: Consider adding creation dates in the document header

## Example Request to Copilot

```
Please create documentation about [topic] and save it to docs/ai/TOPIC_NAME.md
Include:
- Brief overview
- Key steps
- Code examples
- Troubleshooting section
```
