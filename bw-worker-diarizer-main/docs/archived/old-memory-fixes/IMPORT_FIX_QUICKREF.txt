│                                                                             │

│ $ export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libjemalloc.so.2             │

└─────────────────────────────────────────────────────────────────────────────┘

┌─ WHAT EACH FIX DOES ────────────────────────────────────────────────────────┐
│ vm.overcommit_memory=1  → Allows memory overcommit (was blocking it)       │
│ jemalloc                → Better allocator, prevents fragmentation         │
│ LD_PRELOAD              → Forces Python to use jemalloc instead of glibc   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ WHY THIS HAPPENS ──────────────────────────────────────────────────────────┐
│ • PyAnnote imports heavy PyTorch/NumPy components                          │
│ • Linux kernel may refuse allocation if overcommit_memory=2 (strict)       │
│ • glibc malloc fragments memory, causing allocation failures               │
│ • jemalloc handles fragmentation better                                    │
